# gputaskman — монитор памяти GPU

Приложение показывает, какие процессы используют GPU, сколько видеопамяти им
принадлежит, какие среды выполнения и файлы моделей обнаружены. Для совместимых
LLM доступны сведения о весах, KV-кэше и вычислительных буферах.

Русский язык включён по умолчанию в этой версии исходного кода. Для запуска
из папки проекта нужны Python 3.11+ и uv:

```powershell
uv sync --locked
uv run --locked gputaskman
```

Короткое имя команды — `gtm`. Английский интерфейс: `--lang en`.
Также можно установить переменную окружения `GPUTASKMAN_LANG` в `ru` или `en`;
параметр `--lang` имеет приоритет. Язык текстовых отчётов, справки и сообщений
меняется вместе с интерфейсом. Имена процессов, моделей, пути, технические
идентификаторы и исходные сообщения сторонних библиотек сохраняются.
Ключи и значения JSON совместимы с прежней версией при любом языке.

## Сворачивание и краткие показатели в Windows

При запуске интерфейса **показатели постоянно видны прямо в свободной области
панели задач**, перед системными значками: загрузка GPU, занятая/общая VRAM
и температура. Наводить мышь или открывать стрелочку скрытых значков не требуется.
Строка остаётся видимой при свёрнутом основном окне.

Строку можно **перетащить левой кнопкой мыши** в другое свободное место панели
задач. Положение и видимость сохраняются между запусками. Правый щелчок
по строке или значку открывает меню; галочка **«Показатели на панели задач»**
включает и скрывает строку. `--no-taskbar` скрывает её только для текущего запуска.

Панель размещается поверх свободной области основной горизонтальной панели
задач, не забирая фокус у других приложений. Windows не резервирует для неё
место: если появившиеся кнопки приложений заняли эту область, передвиньте строку.
Она следует за размерами панели задач и масштабом экрана, скрывается вместе
с автоматически скрываемой панелью и во время полноэкранного приложения.
Другие мониторы и сторонние замены панели задач не проверены на оборудовании.

Также появляется значок в области уведомлений Windows
(возле часов; Windows может поместить его в меню скрытых значков).
При наведении отображаются загрузка GPU, занятая и общая VRAM, температура.
Для нескольких GPU показатели выводятся отдельно. Длинная подсказка сокращается
с многоточием. Никакие показатели разных карт или процессов не суммируются.
Источник температуры сохраняется, если драйвер его уточняет; память Intel
с оценочным общим объёмом отмечена `≈`.

Краткие показатели также обновляются в заголовке консольного окна — они
доступны после обычного сворачивания на панель задач. Отображение заголовка
вкладки Windows Terminal зависит от настроек самого терминала.

- **t** сворачивает обычное консольное окно на панель задач.
- Двойной щелчок по значку возвращает обычное консольное окно.
- Правый щелчок открывает меню «Открыть монитор», «Свернуть», «Выход».
- В **Windows Terminal** используйте штатные кнопки окна и панель задач
  для сворачивания и восстановления. В его меню значка команды управления
  окном недоступны: приложение не управляет общим окном с другими вкладками.
- Сбор данных продолжается в свёрнутом состоянии. На паузе в кратких
  показателях появляется **[ПАУЗА]**.
- При выходе значок удаляется, прежний заголовок восстанавливается.

Параметр `--no-tray` отключает всю интеграцию Windows: строку, значок и обновление
заголовка. В Linux, WSL
и macOS эта интеграция Windows не запускается. Если область уведомлений
недоступна, приложение показывает причину и продолжает мониторинг.

Ограничение Windows Terminal описано в документации Microsoft:
[GetConsoleWindow и псевдоконсоли](https://learn.microsoft.com/en-us/windows/console/getconsolewindow).

## Управление

| Клавиша | Действие |
|---|---|
| ↑ / ↓ | Выбрать процесс и открыть его сведения |
| s | Сменить сортировку |
| c | Переключить график; также доступно меню «Графики» |
| a | Показать все процессы или основные |
| m | Краткий мониторинг / подробная диагностика |
| p | Пауза / продолжение |
| t | Свернуть обычную консоль Windows |
| ? | Подробная справка об источниках и ограничениях данных |
| Ctrl+P | Поиск команд |
| q | Завершить работу |
| Esc | Закрыть справку или меню команд |

## Отчёты и запись

```powershell
uv run --locked gputaskman --list-gpus
uv run --locked gputaskman --once
uv run --locked gputaskman --json
uv run --locked gputaskman --gpu 0 -i 2
uv run --locked gputaskman record -o session.jsonl --interval 1 --duration 60
uv run --locked gputaskman diff before.json after.json
uv run --locked gputaskman diff before.json after.json --lang en
```

`--no-system` отключает сбор системных ОЗУ/ЦП; `--no-host` в WSL отключает
счётчики Windows. Запись `record` добавляет по одному снимку JSON на строку;
перевод и значок в этом режиме не добавляют сборщиков или опросов GPU.

## Как читать данные

Измерения, косвенные выводы, оценки и данные среды выполнения имеют разный
смысл. В итог входят только **измеренные байты**. Неизвестное значение
показывается как `n/a` / `N/A`, а в JSON — `null`; измеренный ноль остаётся нулём.
Отсутствие данных VRAM не означает отсутствия данных о загрузке движков.

Основания определения модели, от более сильного к более слабому:
`api` → `mapped` → `cmdline` → `path-arg` → `installed`.
`path-arg` сам по себе не доказывает загрузку и не даёт оценок весов/KV-кэша.
Выбранная в настройках модель не обязательно загружена; запись журнала
описывает событие в прошлом. Подсказка типа модели по имени остаётся предположением.

`*` означает однозначное косвенное сопоставление владельца либо одинаковые
до байта размеры во всех подходящих объяснениях. `?` — эвристический выбор
владельца. В WSL строки Linux входят в общий объём ВМ и повторно не прибавляются.
Столбец «Выгр.≈» — оценка нерезидентной памяти, которая не доказывает подкачку
на диск. Развёрнутые объяснения для Windows, Linux, Intel/AMD DRM, WSL
и macOS доступны по **?** и в [основном README](README.md).

## Проверка этой доработки

Локально: Windows 11 build 26200, NVIDIA GeForce RTX 3060 12 ГБ,
драйвер 610.88, обычная нагрузка рабочего стола; новые нагрузки не запускались.
Постоянная строка отрисована на этой машине; перетаскивание и контекстное меню
проверены через computer-use на тестовом окне с тем же отрисовщиком. Тестовый
вариант допускает фокус для инструмента проверки; рабочая строка использует
NOACTIVATE/TOOLWINDOW и не создаёт дополнительную кнопку приложения.
Обновление геометрии и текста занимало около 0,42 мс (медиана), до 1,56 мс;
это не включает последующую асинхронную отрисовку. Дополнительных опросов GPU нет.
Проверены `--once`, JSON, создание/обновление/удаление нативного значка
и завершение его потока. Русский интерфейс, справка, совместимость JSON,
пауза и различие неизвестного значения и нуля проверяются автоматическими тестами.
Сворачивание и восстановление обычной консоли проверены моками Win32 API;
команды сворачивания и восстановления через меню вручную не проверены.

Тестам DRM с символическими ссылками нужны соответствующие права Windows
или Linux: в этой Windows-сессии они завершаются WinError 1314.
